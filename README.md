# 📦 Case Rush – Case Opening

Ein Case-Opening-Browserspiel im CS-Stil.

- 11 Kisten: Gratis (alle 30 Sek.) bis 10.000 $
- 242 verschiedene Skins in 6 Seltenheiten: Gewöhnlich, Selten, Super selten, Episch, Legendär, Mythisch
- Skins verkaufen oder im Inventar behalten, mit dem Geld neue Kisten öffnen
- Fette Animationen bei Episch, Legendär und Mythisch
- Der Spielstand wird im Browser gespeichert (localStorage)

## Chancen
| Seltenheit | Chance |
|---|---|
| Gewöhnlich | 55 % |
| Selten | 25 % |
| Super selten | 12 % |
| Episch | 5,5 % |
| Legendär | 2 % |
| Mythisch | 0,5 % |

## Spielen
Einfach `index.html` im Browser öffnen – oder über GitHub Pages.
